## 🌟 What is CyberNote?

**CyberNote** is a modern, high-performance, hierarchical note-taking workstation built for cybersecurity professionals, software developers, researchers, and power users. 

It uniquely merges:
* 🌲 **The deep multi-level tree structure of CherryTree**
* ⚡ **The instant micro-synchronization speed of Google Keep**
* ☁️ **Seamless Google Drive two-way cloud sync**
* 🛡️ **Zero-knowledge client-side AES-256-GCM encryption**
* 📱 **A true 100% Offline-First Progressive Web App (PWA) architecture**

No subscriptions, no mandatory account sign-up, zero backend server dependencies — CyberNote runs completely inside your browser and can be installed as a native app on any device.

## ✨ Comprehensive Features

### 🌲 1. Hierarchical Tree Notebook
* **Infinite Multi-Level Tree**: Create root notes, nested sub-notes, and multi-level branches with zero depth limits.
* **Folder vs. Note Specialization**: Organize nodes as folders or dedicated rich-text document notes.
* **Custom Node Icons & Colors**: Choose from dozens of SVG vector icons and color-code branches for instant visual clarity.
* **Dedicated Folder Explorer**: Select any folder node to open an intuitive card-based sub-item grid with item counters and quick access.
* **Pin Favorite Notes**: Pin vital documentation and critical credentials to the top of your sidebar for instant access.
* **Read-Only Lock Mode**: Protect sensitive notes from accidental keyboard edits with a single click.
* **Individual Note Password Lock**: Lock private individual notes with client-side SHA-256 / PBKDF2 encryption, custom password hints, and hidden previews.

---

### 📱 2. 100% Offline-First PWA Architecture
* **Native IndexedDB Engine (`CyberNoteDB`)**: All notes, metadata, and tree relations are stored locally in IndexedDB for instant, zero-latency access.
* **Works Completely Offline**: Turn on Airplane Mode or disconnect from the internet — CyberNote continues to launch, navigate, create, edit, and search notes with zero interruption.
* **Offline Sync Queue**: Any note edits, creations, or deletions made offline are queued locally and automatically synchronize to Google Drive the moment your internet connection returns.
* **Dual-Layer Storage Safety**: Seamless automatic fallback to GZIP-compressed `LocalStorage` ensures your data is never lost, even on browsers with restricted storage.
* **Native App Installability**: Install directly from the browser onto Android, iOS, Windows, macOS, and Linux with native standalone window styling.

---

### ☁️ 3. Google Drive Two-Way Multi-Device Sync
* **Google Identity Services (GIS OAuth 2.0)**: Secure, modern sign-in using your existing Google account.
* **Privacy-First Scope (`drive.file`)**: CyberNote requests access **strictly to files created by CyberNote**. It has **zero access** to your private photos, Google Docs, or other Drive files.
* **High-Speed Hierarchy Manifest (`cn_manifest.json`)**: Loads your entire notebook hierarchy in a single network request without sequential downloading delays.
* **Intelligent Candidate Folder Selection**: Automatically discovers and binds to the active `CyberNote` folder across multiple devices, self-healing duplicate folders.
* **Multi-Device Conflict Detection**: If notes are edited on both your phone and PC, CyberNote presents a visual **Conflict Resolution Modal** letting you merge both, pull remote notes, or push local changes safely.
* **Legacy Single-Backup Migration**: Automatically detects and migrates older `CyberNote_Backup.json` archives into the modern per-node file architecture.
* **Continuous Auto-Backup**: Changes are automatically debounced and synced in the background as you write.

---

### 🔒 4. Military-Grade Client-Side Security (E2EE)
* **AES-256-GCM End-to-End Encryption**: Optional client-side encryption using the Web Crypto API.
* **Key Derivation (PBKDF2)**: Derives cryptographic keys using PBKDF2 with 100,000 hashing rounds and cryptographically secure random salts.
* **Zero-Knowledge Architecture**: Your notes are encrypted inside your browser *before* leaving your device. Even Google's servers cannot view the plaintext content of your notes.

---

### 🎨 5. Modern Studio Ribbon & WYSIWYG Editor
* **Direct In-Place Editing**: What You See Is What You Get — edit directly on the page without awkward split-screen markdown previews.
* **Microsoft Word-Style Ribbon**: Clean, responsive tabs including **Home**, **Insert**, **Studio**, **Tools**, **Format**, and **Help**.
* **Floating Selection Bubble Toolbar**: Highlights text to provide immediate formatting shortcuts and quick conversions.
* **Interactive Slash Commands (`/`)**: Type `/` inside any blank line to invoke headings, code blocks, tables, callout boxes, and divider lines.
* **Windows Paint Studio Canvas**: Integrated digital canvas for quick sketches, diagrams, and handwriting.
* **Smooth Handwritten Signature Studio**: Vector Bezier curve interpolation captures authentic, smooth signatures that insert directly into notes.
* **Interactive Geometric Shape Studio**: Add resizable, transparent vector circles, rectangles, stars, triangles, and floating text callouts with free repositioning.
* **Interactive Tables**: Insert tables, add/delete rows and columns dynamically, and resize column widths directly with mouse or touch.
* **Text Animation Effects**: Apply dynamic CSS glowing animations (Glitch, Shimmer, Neon, Flame, Hue, Bounce, Pop).
* **Callout Alert Boxes**: Insert color-coded Tip, Warning, Danger, and Info alert boxes with custom icons.
* **Interactive Todo Tasks**: Checkboxes with strike-through styling for tracking project milestones.
* **1-Click Code Boxes**: Formatted syntax code boxes with language badges and an instant "Copy Code" button.
* **Direct Clipboard Screenshot Pasting (`Ctrl + V`)**: Paste images directly from your clipboard into your notes with interactive image resize handles and alignment tools.

---

### 🔍 6. Deep Global Search & Categorization
* **Instant Deep Search (`Ctrl + K`)**: Lightning-fast search through note titles, tags, and full HTML note bodies.
* **Interactive Tag Chips**: Assign comma-separated tags to any note and filter your knowledge base with a single click.
* **Breadcrumb Navigation**: Path trail at the top of every note showing exact position in your hierarchical tree.
* **Live Word & Character Counter**: Real-time stats display in the bottom status bar.

---

### 📤 7. Importers & Backup Portability
* **CherryTree Importer (`.ctb` / `.ctd`)**: Import legacy CherryTree SQLite or XML databases directly into CyberNote with full hierarchy preservation.
* **JSON Backup Export & Import**: One-click manual backup download and restore for local archival.
* **Direct GitHub Sync**: Connect your personal GitHub repository via token to maintain a secondary git-versioned backup of your notes.

## 📱 Installation Guide (Progressive Web App)

CyberNote is a Progressive Web App (PWA) that installs on your device just like a native store application.

### 🤖 Android (Google Chrome / Brave / Edge)
1. Open [https://prekarshamaxx123.github.io/CyberNote/](https://prekarshamaxx123.github.io/CyberNote/) in Chrome.
2. Tap the **three dots menu (⋮)** in the top right corner.
3. Tap **"Install app"** or **"Add to Home screen"**.
4. Tap **Install**. CyberNote is now in your app drawer and works 100% offline!

### 🍏 iPhone & iPad (Safari)
1. Open [https://prekarshamaxx123.github.io/CyberNote/](https://prekarshamaxx123.github.io/CyberNote/) in Safari.
2. Tap the **Share button** (the square icon with an upward arrow at the bottom).
3. Scroll down and tap **"Add to Home Screen"**.
4. Tap **Add** in the top right corner. The CyberNote app icon will appear on your iOS home screen.

### 💻 Windows / macOS / Linux (Chrome / Edge / Brave)
1. Open [https://prekarshamaxx123.github.io/CyberNote/](https://prekarshamaxx123.github.io/CyberNote/).
2. Click the **Install icon** in the browser URL address bar (or go to browser menu -> **Apps** -> **Install CyberNote**).
3. Launch CyberNote as a standalone desktop window from your start menu or desktop shortcut.

## 🛠️ Local Development & Self-Hosting

### Quick Start with Node.js
CyberNote requires Node.js (v18+) for optional local server mode, or can be served by any static web server:

```bash
# 1. Clone the repository
git clone https://github.com/Prekarshamaxx123/CyberNote.git
cd CyberNote

# 2. Start local server
npm start
# or: ./start.sh
```

Open `http://localhost:3000` in your browser.

### Self-Hosting on GitHub Pages (100% Free)
1. Fork or push this repository to your GitHub account:
   ```bash
   git remote add origin https://github.com/<YOUR_USERNAME>/CyberNote.git
   git push -u origin main
   ```
2. Navigate to your repository **Settings** -> **Pages**.
3. Under **Build and deployment** -> **Source**, select **GitHub Actions**.
4. The included workflow `.github/workflows/deploy.yml` will automatically build and publish your instance to:
   ```
   https://<YOUR_USERNAME>.github.io/CyberNote/
   ```

## 🛡️ Security & Privacy Disclosures

* **Zero Tracking / Zero Telemetry**: CyberNote contains no analytics trackers, advertising scripts, third-party cookies, or fingerprinting scripts.
* **Isolated Client Storage**: All notes and encryption keys remain exclusively on your local device unless you explicitly sign in with Google or connect a GitHub repository.
* **Restricted OAuth 2.0 Scope**: CyberNote strictly uses the `https://www.googleapis.com/auth/drive.file` scope, meaning it cannot access, read, or modify any files outside of its own notebook folder.
* **Open Source**: The full source code is publicly accessible and auditable.
